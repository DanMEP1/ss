# Совок-Сити (sovokcity) — мод для Minecraft 1.21.1 / NeoForge

Реалистичное выживание в «совковом» городе-диктатуре.

## Что внутри
**Реализм**
- Жажда (0–100): падает со временем, быстрее при беге, жаре и болезни. Утоляют: кипячёная вода, компот, бутылки с водой, кружка (сырая вода = риск дизентерии).
- Температура тела: зависит от биома, ночи, дождя, высоты, воды, помещения, брони и источников тепла (огонь, печь, костёр, лава).
- Болезни: простуда (от переохлаждения), дизентерия (сырая вода, сырое мясо). Лечатся «Таблетками».
- HUD слева сверху (жажда, температура, болезни, розыск, срок ареста).

**Город (строится автоматически при первом входе, 97x97, вокруг мирового спавна)**
- Площадь с памятником Вождю, стена с вышками, хрущёвки с кроватями.
- Продмаг + пункт талонов (3 талона на человека в игровые сутки; 1 талон = 1 паёк).
- Легальное казино «Красный Октябрь»: автоматы «Спортлото» (5 руб.).
- Подпольное казино: подвал в юго-западной хрущёвке (вход по лестнице из подъезда). Крупье продаёт **Upgrader** за рубли, спекулянт торгует дефицитом.
- Милиция (8 патрульных): видят игрока в зоне подпольного казино, пока он крутит Upgrader (ПКМ, команда /upgrade*, либо стоит с Upgrader в инвентаре) — бегут и **арестовывают**: камера, штраф (половина рублей), конфискация Upgrader, срок из конфига. Патруль иногда заглядывает в подвал сам.
- Комендантский час ночью (настраивается).

## Сборка
Нужны JDK 21 и Gradle 8.8+ (или импорт в IntelliJ IDEA).
```
gradle build        # jar появится в build/libs/
gradle runClient    # запуск для теста
```
Кладите jar в `mods/` вместе с Upgrader Items (NeoForge 1.21.1).

## Настройка (config/sovokcity-common.toml)
- `upgraderItemId` — ID предмета Upgrader из мода (по умолчанию `upgrader_items:upgrader`; точный ID смотрите в игре через F3+H и поправьте).
- `upgraderPrice`, `jailSeconds`, `patrolCount`, `curfew`.

## Команды
`/sovok info` — координаты мест; `/sovok pardon` и `/sovok hideout` (оп).

## Важно
Код написан без возможности компиляции в среде разработки (нет доступа к maven NeoForge), поэтому возможны мелкие ошибки API — пришлите вывод `gradle build`, поправлю. Лучше всего город строится на ровной местности (суперплоский мир или равнина).
